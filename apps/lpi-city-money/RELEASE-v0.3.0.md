# LPI City Money v0.3.0 release metadata

Release this merged version after the Windows and Android build jobs pass.

Highlights:
- Original purple wallet UI with SVG icons and responsive animations.
- Review-before-pay modal, slide-to-confirm, and animated game receipts.
- Optional device platform-authenticator prompt where supported.
- Personal LPI player QR/pay code with sender-chosen game-coin amount.
- Saved issued gift-code history and cross-style LPI gift-card redemption.
- Admin-controlled daily spin, disabled by default until activated.

All balances are fictional LPI game coins. This is not PhonePe, UPI, or a real-money payment app.
